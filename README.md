# Тренажёр CCNA 200-301

Учебное приложение по курсу [Jeremy's IT Lab — Free CCNA v1.1](https://www.youtube.com/playlist?list=PLxbwE86jKRgMpuZuLBivzlM8s2Dk5lXBQ):
карточки с интервальным повторением, мини-лекции по дням курса, тренажёр подсетей,
ввод команд IOS, кейсы «найди неисправность», задания на сопоставление и режим «Микс»,
который перемешивает всё это в одну сессию.

Работает целиком в браузере: сервера нет, прогресс хранится в браузере посетителя.

## Как это опубликовать на GitHub Pages

1. Создайте репозиторий на github.com: **New repository** → имя, например `ccna-trainer`,
   видимость **Public** (Pages на бесплатном тарифе работает только с публичными репозиториями),
   без README.
2. На странице пустого репозитория нажмите **uploading an existing file** и перетащите
   туда **всё содержимое этой папки** (файлы, не саму папку). Нажмите **Commit changes**.
3. **Settings** → **Pages** → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через минуту-две адрес появится там же: `https://ВАШ-ЛОГИН.github.io/ccna-trainer/`

## Как обновлять

Заменить изменившиеся файлы в репозитории (кнопка **Add file → Upload files**)
и поднять номер версии `VER` в `sw.js` — иначе у тех, кто уже открывал сайт,
останется старая версия из кеша.

## Состав

| Файл | Что внутри |
|---|---|
| `index.html` | разметка и все стили |
| `bank-a.js`, `bank-b.js` | банк вопросов с разборами |
| `lessons.js` | мини-лекции по дням курса |
| `glossary.js` | термины для всплывающих пояснений |
| `drills.js` | генераторы задач: подсети, системы счисления, маршруты, MAC-таблица |
| `cli.js` | задания на ввод команд IOS |
| `cases.js` | кейсы «найди неисправность» |
| `match.js` | задания на сопоставление |
| `core.js`, `ping.js`, `app.js` | хранилище, персонаж Пинг, режимы и отрисовка |
| `sw.js`, `manifest.webmanifest`, `icon-*.png` | работа без интернета и иконка на домашнем экране |

## На телефоне

Откройте сайт в Safari → «Поделиться» → **«На экран „Домой“»**. Приложение запустится
без адресной строки и будет работать даже без сети.
