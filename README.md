# Тренажёр CCNA 200-301

Учебное приложение по курсу [Jeremy's IT Lab — Free CCNA v1.1](https://www.youtube.com/playlist?list=PLxbwE86jKRgMpuZuLBivzlM8s2Dk5lXBQ):
карточки с интервальным повторением, мини-лекции по дням курса, учебный маршрут для первых 15 дней,
тренажёр подсетей,
ввод команд IOS, кейсы «найди неисправность», сопоставления и режим «Микс», который
перемешивает всё это в одну сессию. Помогает и подбадривает персонаж Пинг.

Приложение работает целиком в браузере: сервера нет, прогресс хранится у пользователя.
В первых 15 днях маршрут ведёт от лекции через три вопроса без подсказок и сетевую ситуацию
к повторению спустя 24 часа. Прочитанное и освоенное учитываются отдельно.

## Как запустить

Открыть `index.html` в браузере. Для полноценной работы (`сервис-воркер`, относительные пути)
лучше поднять любой статический сервер в этой папке — например, расширение Live Server
в редакторе. Внешних зависимостей и сборки нет: обычные файлы, которые браузер читает как есть.

## Что где лежит

| Папка | Что внутри |
|---|---|
| `styles/` | оформление: токены, каркас, компоненты, экраны, узкие экраны |
| `data/` | содержимое курса: карточки, лекции, термины, задания. Логики здесь нет |
| `app/` | механизмы: хранилище, повторение, схемы, персонаж, настройки, события |
| `app/screens/` | по файлу на каждый экран приложения |

Подробная карта с описанием каждого файла — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Частые правки

**Добавить карточку.** Открыть `data/cards-basics.js` (дни 1–29) или `data/cards-advanced.js`
(дни 30–63) и дописать объект в массив:

```js
{id:"b99",b:0,day:5,q:"Текст вопроса?",
 o:["Вариант A","Вариант B","Вариант C","Вариант D"],a:[1],
 why:"Почему верен вариант B.",
 no:["Почему не A.","","Почему не C.","Почему не D."]}
```

`id` — уникальный, `b` — номер блока курса (0–7), `day` — день курса, `a` — индексы верных
ответов. Необязательные поля: `c` — вывод команд, `fig` — схема сети (см. `app/diagram.js`).

**Добавить лекцию.** `data/lessons.js`, формат описан в шапке файла.

**Добавить термин для всплывашки.** `data/glossary.js`: `m` — основы слов, по которым термин
находится в тексте.

**Поменять цвета или размеры.** Основная палитра текущего оформления задана в
`styles/signal.css`; общие базовые токены — в `styles/tokens.css`. Маршрут урока оформлен в
`styles/course.css`.

## Публикация

- **Один файл.** Собрать всё в `ccna-trainer-offline.html` и отправить кому угодно — работает без интернета.
- **GitHub Pages.** Сайт публикуется из корня репозитория; `sw.js` кэширует файлы для офлайн-доступа.

## Порядок подключения

Файлы — обычные скрипты и делят общую область видимости, поэтому **порядок в `index.html`
важен**: сначала содержимое (`data/`), затем ядро (`app/globals.js` и далее), затем экраны,
затем оболочка и `app/main.js`, который запускает приложение. Новый файл добавляется в этот
же список, в свою группу.
