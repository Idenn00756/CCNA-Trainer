# Карта проекта

Приложение собрано из обычных скриптов без сборщика и фреймворков. Все файлы делят одну
область видимости: объявленное в одном доступно в остальных. Отсюда два правила:

1. **Порядок подключения в `index.html` важен.** Сначала данные, потом ядро, потом экраны,
   потом оболочка. Запускает всё `app/main.js` — он подключается последним.
2. **Имена не повторяются.** Одно имя объявляется ровно в одном файле, иначе браузер
   остановится с ошибкой «уже объявлено».

## Оформление — `styles/`

| Файл | Что описывает |
|---|---|
| `tokens.css` | цвета, тени, скругления, шрифты. Светлая тема — основа, тёмная повторяет тот же набор имён. Менять внешний вид следует здесь |
| `base.css` | сброс, шапка, основная колонка, нижняя навигация |
| `components.css` | повторяющиеся элементы: карточка, варианты ответа, разбор, кнопки, Пинг с анимациями, фильтры, схемы, всплывашки, настройки |
| `screens.css` | оформление отдельных экранов: главный, итоги, практика, команды, сопоставление, лекции, прогресс |
| `responsive.css` | правила для узких экранов. Подключается последним |

## Содержимое курса — `data/`

Чистые данные, без логики. Каждый файл кладёт массив в `window`.

| Файл | Что внутри | Что даёт |
|---|---|---|
| `cards-basics.js` | блоки курса, названия дней, карточки дней 1–29 | `BLOCKS`, `DAYS`, `BANK` |
| `cards-advanced.js` | карточки дней 30–63 | дополняет `BANK` |
| `lessons.js` | мини-лекции по дням курса | `LESSONS` |
| `glossary.js` | термины для всплывающих пояснений | `GLOSSARY` |
| `cli-tasks.js` | задания на ввод команд IOS | `CLI` |
| `cases.js` | кейсы «найди неисправность» | `CASES` |
| `match-sets.js` | наборы на сопоставление | `MATCH`, `MATCH_GEN` |
| `drills.js` | генераторы задач: подсети, системы счисления, маршруты, MAC-таблица, жизнь пакета | `DRILLS` |

## Ядро — `app/`

| Файл | Отвечает за |
|---|---|
| `globals.js` | ссылки на данные, список режимов, мелкие помощники (`esc`, `shuffle`, `plural`, `pct`) |
| `storage.js` | объект прогресса `P`: загрузка, миграции со старых версий, сохранение, слияние с облаком |
| `day-goal.js` | дневная статистика, выполнение цели дня, подсчёт серий |
| `srs.js` | интервальное повторение: когда показать карточку снова |
| `diagram.js` | отрисовка схем сети в SVG и их текстовое описание для Claude |
| `glossary-popup.js` | поиск терминов в тексте и всплывающее пояснение |
| `claude.js` | обращение к Claude: правила ответа, форматирование, обработка ошибок |
| `achievements.js` | достижения и всплывающие уведомления |
| `ping.js` | персонаж: рисунок, настроения, анимации, реплики, статус дня, огонёк серии |
| `nav.js` | четыре основных раздела и заголовки экранов |
| `settings.js` | меню настроек: блоки курса, цель дня, тема, Пинг, сброс |
| `feedback.js` | подтягивание разбора в поле зрения и кнопка «Отзыв» |
| `render.js` | общая отрисовка: какой экран показать, шапка, показатели, панель фильтров |
| `events.js` | все нажатия и клавиатура в двух обработчиках на документе |
| `main.js` | запуск приложения, синхронизация прогресса, подключение Claude и отзывов |

## Экраны — `app/screens/`

| Файл | Экран |
|---|---|
| `home.js` | выбор следующего учебного шага для главного экрана |
| `training.js` | единый выбор карточек, задач, команд, кейсов, сопоставлений и смешанной сессии |
| `mix.js` | «Микс»: сборка смешанной сессии и её итоги |
| `cards.js` | карточки: очередь, ответ, оценка, итоги сессии |
| `cards-ask.js` | вопрос к Claude по открытой карточке |
| `lessons.js` | лекции: оглавление, чтение, вопрос к Claude по теме |
| `practice.js` | задачи-генераторы и проверка ответов |
| `cases.js` | кейсы: диагноз и исправление в консоли |

## Как хранится прогресс

Всё лежит в одном объекте `P` (см. `app/storage.js`) и сохраняется в браузере под ключом
`ccna-trainer-v3`. На GitHub Pages облачной синхронизации нет: прогресс остаётся на устройстве.

| Поле | Что хранит |
|---|---|
| `cards` | по каждой карточке: сколько раз показана, верных, неверных, интервал, дата следующего показа |
| `cli`, `cases`, `match` | решённые задания и их качество |
| `sub` | статистика задач по темам: количество, точность, время |
| `days` | по дням: сколько карточек и задач сделано, сколько верно |
| `read` | прочитанные лекции |
| `terms`, `asks` | открытые термины и число вопросов к Claude |
| `ach` | достигнутые уровни достижений |
| `goal`, `ui` | цель дня и настройки: блоки, тема, режим, персонаж |

## Публикация

GitHub Pages открывает `index.html` из корня репозитория. После изменения подключаемых
файлов нужно обновить список `SHELL` и версию кэша в `sw.js`, чтобы новая сборка
обновилась и при работе без сети.
